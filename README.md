# マイ敷き詰めメーカー Ver.1

手づくりタイルの写真から、敷き詰め模様を作る教育用の静的Webアプリです。HTML / CSS / JavaScriptのみを使用し、外部ライブラリ、通信、サーバー、APIは不要です。

## 起動・公開

`index.html` をブラウザで開いて使用できます。ローカルHTTPで確認する場合は、このディレクトリで `python3 -m http.server 8000` を実行します。

GitHub Pagesでは、この3ファイル（index.html / style.css / app.js）を含むブランチのルートを公開元に設定してください。ビルドは不要です。

## 使い方

1. 写真を選びます。JPEG・PNGなどブラウザで読み込める形式に対応します。
2. 写真で背景部分をタップし、スライダーで削除の強さを調整します。残った背景は何度でもタップして追加削除できます。やり直しはすべての削除を取り消し、元の画素に戻ります。
3. 「タイルを追加」を押して好きな枚数を配置します。ドラッグで移動し、選択したタイルを30°刻みで回転、左右反転、拡大縮小、削除できます。
4. 「画像として保存」で制作エリアを1200×800のPNGに書き出します。保存されない端末では表示されたリンクから画像を開いて保存してください。

## Ver.1の仕様

- 画像はブラウザ内で処理します。処理用画像は長辺1400px以下に縮小します。HEICなど読み込めない形式はJPEG・PNGに変換してください。
- タップ地点を起点とするFlood Fill（上下左右の4方向）で、起点の色とのRGB差の二乗平均平方根がthreshold以下の連続した領域だけを透明化します。離れた同色領域や輪郭で囲まれた内部には届きません。ただし輪郭に隙間がある場合や、強さを上げすぎた場合は内部までつながることがあります。
- 追加タップ時にそれまでの削除を確定し、スライダーは最後にタップした領域だけを再計算します。それ以前の透明部分は維持します。透明な場所のタップは何も変更しません。
- 透明な余白を切り詰めてタイル化します。背景削除設定は以降に追加するタイルに適用され、配置済みのタイルは変わりません。
- タイルの枚数に固定の上限はありません。実際の上限は端末の性能に依存します。
- 拡大率は20〜500%。回転中心はタイルの中心です。反転はタイル自身の左右方向で行います。
- 透明部分のクリックは下のタイルに届きます。「次のタイルを選択」で重なったタイルも選べます。制作エリアにフォーカスした状態では矢印キーで移動できます（Shiftで大きく移動）。
- タッチ移動はPointer Eventsを使用します。制作エリア外からページをスクロールしてください。
- 保存画像は白い背景です。タイルの透明部分から下のタイルや白い背景が見えます。選択枠や操作UIは含まれず、制作エリアの外側は切り取られます。
- リセットは確認後に配置を消去し、読み込んだ写真は保持します。編集データの永続保存はありません。

## テスト

Chrome + Playwrightによるブラウザテストを `tests/browser.cjs` に用意しています。アプリ自体にはPlaywrightは必要ありません。

ローカルサーバー起動後、Playwrightを利用できるNode.js環境で `node tests/browser.cjs` を実行します（Chromeが必要です）。

確認済み：画像読み込み、背景色クリック／タップ、threshold再計算、タイル追加、マウス移動、タッチ入力による移動、左右30°回転、左右反転、拡大縮小、削除、リセット、背景削除やり直し、PNGダウンロード、PNGの画素比較、スマートフォン幅の横はみ出し防止。

Flood Fillの追加テスト：黒い輪郭内の白色保持、分離した3領域の順次削除、最後の領域のみのthreshold再計算、以前の削除の保持、透明部分の再タップ、全画素一致による元画像への復元を確認しました。

タッチ操作はChromeのモバイルエミュレーションで確認しました。iPad・iPhoneのSafari実機での保存操作は未確認です。

## タイルごとの色変更

制作エリアでタイルを選択し、「タイルの色」のカラーピッカー、または赤・青・黄・緑のプリセットで色を指定できます。色は配置した1枚ずつ保持します。「元の色に戻す」はその1枚の色変更だけを解除します。新しく追加したタイルは元の色です。

元画像の明暗から選択色に陰影を付け、色の適用強度を65%に抑えて元画像の白っぽさ・質感を残します。濃い線は元の画素を保持します。透明度（半透明を含む）は変更しません。色変更は毎回元のタイル画像から計算するため、繰り返し変更しても劣化が累積しません。表示とPNG保存で同じ色付き画像を使います。

`node tests/color.cjs` で個別色、カラーピッカー／プリセット、陰影・濃い線・透明度保持、元の色への復元、変形・移動後のPNG色確認と画面一致、削除、スマートフォン幅の表示を検証できます。Chromeでテスト済みです。
